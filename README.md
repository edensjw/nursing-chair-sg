# Nursing chairs under S$80 · Carousell Singapore

A static, filterable shortlist of live nursing-chair, glider and rocker listings on
carousell.sg at S$80 or less, built 18 Nov 2026.

- `index.html` — the page (open directly, or via GitHub Pages)
- `assets/` — listing photos stored locally
- `og.png` — social preview image

Every listing's photos were opened individually and assessed: fabric condition,
visible staining, whether the mechanism shown matches the seller's description,
and whether the thing is even a nursing chair. Cards carry a verdict —
**Top pick**, **Worth a look**, **Compromise** or **Skip**.

Prices, conditions and meet-up areas are as stated by each seller at scrape time.
Nothing here is a live availability check — always confirm on Carousell before
travelling.
